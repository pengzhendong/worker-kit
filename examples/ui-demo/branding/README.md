# WorkerKit 图标构造

保留 B 方案的方形回环、直边和中央窗口。圆用于控制转折与切缝，不把整个外轮廓画成圆形。当前默认色为低饱和蓝灰 `#6574AD`。

在 128 × 128 坐标系中构造一片，再围绕 (64, 64) 旋转 90°、180°、270°：

- R22 圆弧连接外侧直边。
- R51.5 主圆与 R22 转角圆在 (34, 12) 相切。
- R54 切除圆与相邻片的主圆同心，形成 2.5 单位基础间隙。
- R1 相切圆角处理两处针尖；坐标由圆心距离求出。

全部曲线使用 SVG `A` 圆弧命令，没有手调的三次贝塞尔曲线。半径以构造单位计，不是屏幕像素。几何关系用于一致性，最终比例仍按实际大小检查。

运行 `node examples/ui-demo/branding/generate.mjs` 生成图标、构造图，并同步 Nuxt 共享 public、原 React 示例与文档站的 favicon。其他后台从 Nuxt 的共享 public 复制。没有修改各框架的主题色。
